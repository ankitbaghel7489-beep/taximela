Questions

Frequently asked.

Answers follow the supplied Taxi Mela app rules; where the app did not define a surcharge or policy, this site does not invent one.

How is outstation fare calculated?

Real road distance is summed across route legs and multiplied by the selected Toll Excluded or Toll Included per-km rate from settings/pricing.

Are destination cities required to be serviceable?

No. Only the pickup city needs to be serviceable. The Cloud Function checks active entries in serviceCities.

Does the fare include GST?

No GST/tax line is added because it is not part of the supplied formula.

How are local rentals priced?

The 20/40/80/120 km package prices are static constants. For custom distances, ≤20 km uses the category’s localFixed price; above 20 km uses distance × live localRate.

How is night halt calculated?

The website calculates nights from the pickup/return date-time difference: ₹500 for the first night and ₹300 for each additional night.

How is the advance calculated?

Advance = base fare × commissionPercent / 100 + pet charge. commissionPercent is read live from settings/pricing.

Can I book directly online?

The current public website captures booking interest in websiteLeads. It does not pretend to confirm a vehicle or process payment unless those capabilities are added separately.
